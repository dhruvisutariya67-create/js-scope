Lexical Scope

Variables resolve based on where functions are defined, not where they are called.

const label = "outer";
function read() { return label; }
function caller() {
  const label = "caller";
  return read(); // "outer"
}

Execution Context

Each call pushes a context to the stack. Closures preserve referenced variables after return.

Closure Isolation

Different instances created from the same factory maintain separate memory environments.

const a = createBankAccount(100);
const b = createBankAccount(200);
a.deposit(50);
a.getBalance(); // 150
b.getBalance(); // 200 (Independent)
